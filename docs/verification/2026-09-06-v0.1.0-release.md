## 拉伸案例

[公开拉伸案例](2026-09-06-public-tensile-surrogate.md)使用 H_08 标定、H_16
检查模型、H_18 作最终实验评估。模型为均匀标距段小应变双线性弹塑性，比较
范围为 0–0.8% 工程应变。12 个真实 FE 算例、84 个阶段和 MLP 结果在案例报告中给出。

这次发行直接采用已完成的求解与训练结果。完整回归之后的修改涉及 README
图片链接、本报告和依赖许可说明，最终发行包随后完成构建与安装验证。
