# v0.2.2 release validation — 2026-09-27

The maintainer approved publication and the 0.2.2 version after reviewing the
second hardening round. This release uses the existing GitHub repository and
Release artifacts. The package, CLI and version-specific metadata links use
0.2.2.

## Changes

Solver fingerprints record the effective command, resolved command-file path,
streaming SHA-256 and optional version output. Explicit
`abaqus.version_probe_args` enables a probe with a three-second execution
timeout and the runner's owned-process cleanup. The initial `runtime.solver`
snapshot stays fixed; each executed datacheck, analysis and extraction stage
records its own fingerprint. Probe execution preserves virtual-environment
launcher paths while recording the resolved target file identity.

The timeout regression uses named timeout/sleep constants and derived lower
and upper bounds. Evaluation-report exit-code semantics have CLI coverage and
an explanation in the operating guide. Historical account notes are appended
to the original records, and the source distribution includes context for its
historical figures and result summary.

## Regression evidence from the hardening round

- The immediate-return mutation was accepted by the original timeout test and
  rejected after adding its derived lower bound. The real test then passed five
  fresh processes on Windows and five on WSL Ubuntu, Python 3.14.4.
- Windows repetition summaries were 1.43, 2.62, 1.38, 1.36 and 1.78 seconds;
  Linux summaries were 3.56, 2.37, 2.56, 2.16 and 1.55 seconds. These are pytest
  session durations. Linux used `--capture=sys` after default file-descriptor
  capture encountered a temporary-file truncate error on DrvFS.
- The initial solver-fingerprint tests failed in 16 cases before implementation.
  An additional POSIX symlink test reproduced a virtual-environment probe
  returning the system prefix. Preserving the selected launcher path fixed it.
  Final targeted results were 78 passed on Windows and 18 passed on Linux,
  including the timeout regression.
- Five CLI characterization cases verify successful report generation with
  met/not_met/holdout findings and errors for missing or changed evidence.

Solver tests use synthetic launchers, including Windows batch files and POSIX
shell/Python helpers. A changed launcher produces a new stage digest/version;
the initial runtime and earlier artifact receipts retain their original values.
Manifest schema remains 0.1 with additive fields. The existing skip gate,
dependency ranges and retry behavior retain their prior contracts.
