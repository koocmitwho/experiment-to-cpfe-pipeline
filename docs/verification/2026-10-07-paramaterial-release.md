# v0.3.1 Paramaterial case validation

This release adds the portable `examples/paramaterial_tensile` case. The core
library API is unchanged. It includes three attributed CC BY 4.0 engineering
stress-strain curves and retains both upstream MIT notices.

## Local validation

Windows, Python 3.12.10:

| Check | Result |
|---|---|
| Complete offline suite | 804 passed, 22 explicitly permitted skips |
| Paramaterial case suite | 14 passed |
| Installed wheel outside the checkout | 1 passed |
| Actual public-wheel case from another working directory | 3 specimens, 1,889 original rows |
| Direct CSV versus HDF5-readback metrics | Nine comparisons, zero difference |
| Independent readback | Numeric values, original row numbers, sample IDs, units and source hashes passed |
| Independent numerical reference | Within the fixed 1e-7 absolute numerical tolerance |

Offline skips concern unavailable Torch and explicitly disabled real-Abaqus
and wheel opt-ins. Wheel installation was subsequently enabled and passed.
Remote CI retains the existing offline, CPU-training and CPU-ML jobs and adds
the installed-wheel Paramaterial case on Windows and Linux. The release page
and GitHub Actions record the completed remote runs.

The isolated validation environment initially lacked pip, which the existing
wheel-installation test invokes. Installing pip in that environment resolved
the test-environment failure; no library repair was needed. Old Paramaterial
dependencies emit deprecation/syntax warnings. The case pins the compatible
numerical/plotting stack and does not modify third-party algorithms.

## Distribution boundary

The source distribution carries the case scripts, three CSV inputs, public
source/reference JSON, notices, tests, bilingual instructions and sanitized
example figures/tables. The wheel carries the library and CLI; obtain the
matching source distribution for the example files.

CSV Git attributes preserve the upstream bytes used by the source hashes.
The public example imports the installed library, not a private checkout.
Local environments, personal activity reports, service sessions, original
full-text papers and generated HDF5/run receipts are excluded from the case
distribution. Runtime receipts generated by users may contain their own
local paths and should be reviewed before sharing.

## Scope

This is a fixed-case processing and provenance verification. It performs no
model training, material calibration or solver run. Numerical consistency is
not independent experimental validation or cross-material generalization.
An earlier local independent-agent usability observation is described as
historical context only, without claiming human time savings or timing this
public release.
