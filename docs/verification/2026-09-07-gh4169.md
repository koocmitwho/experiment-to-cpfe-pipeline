## 数据与评估

DATA.xlsx 和六张金相 JPG 已从刷新后的公开文件 API 下载，全部与清单大小和
内容摘要一致。本轮普通下载由 302 跳转到公开存储并返回 200；此前 403 的
障碍未再出现。源数据使用 CC BY-NC 3.0，原文件及衍生数据、模型、图表均保留
在忽略目录。所有工作表和嵌入表头已检查，具体字段、异常和处理选择见
[案例说明](../../examples/gh4169_ultrasonic/README.md)。

输入固定为平均衰减系数和平均纵波声速，目标为金相平均晶粒直径。开发集八件
试样使用四对外层留出、三对内层验证，最终保留作者 T1/T2。现有 MLP 的
训练/验证/测试接口保持不变，至少两行的约束也保持不变。

| 方法 | 开发集外层 MAE / RMSE（n=8，μm） | 作者测试 MAE / RMSE（n=2，μm） |
| --- | ---: | ---: |
| 均值 | 44.9977 / 51.8441 | 20.6151 / 27.2159 |
| OLS | 9.1752 / 10.0018 | 5.5388 / 5.7084 |
| 岭回归 | 10.3065 / 11.4099 | 5.9598 / 5.9604 |

外层 MLP 成员训练样本数为四，最终成员为六；基线分别用六/八个开发试样
重新拟合。部分 MLP 的最佳 checkpoint 位于第一轮或最大训练轮，显示小样本
选择的不稳定。固定网络没有超过 OLS；这份同研究来源的十试样数据不足以
支持跨批次、设备条件的可靠预测结论。没有生成样本或复用作者拟合结果。
