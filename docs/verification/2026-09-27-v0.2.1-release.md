The two skips are the disabled Abaqus and wheel integration opt-ins. The wheel
test was subsequently enabled for the final release artifact, alongside the


Both wheel and sdist build successfully and pass `twine check --strict`.
The wheel contains 79 files, and the sdist contains 205 files. Archive inspection

the checksum script and CI workflow, and zero matches for the retired numeric
owner identifier. Every packaged Python/resource file matches the source
candidate byte-for-byte. `SHA256SUMS.txt` accompanies the release artifacts.

Local repair details and the original red/green evidence are preserved in the
[repair record](2026-09-27-validation-ci-hardening.md). The source review retains

## CI and installation

The release workflow uses a pull request and the four tests jobs: Ubuntu
offline, Windows offline, CPU training and CPU ML. The offline jobs also build
and verify an installed wheel outside the source checkout. The ML job executes
the real PyG test and the complete suite with the skip gate enabled.

The tagged revision and downloadable artifact receipts are linked from the
[v0.2.1 release](https://github.com/koocmitwho/experiment-to-cpfe-pipeline/releases/tag/v0.2.1).
Install its wheel in an activated environment with:

```text
python -m pip install "https://github.com/koocmitwho/experiment-to-cpfe-pipeline/releases/download/v0.2.1/experiment_to_cpfe-0.2.1-py3-none-any.whl"
pipeline --version
```

CI runs and their exact revisions are available in
[GitHub Actions](https://github.com/koocmitwho/experiment-to-cpfe-pipeline/actions/workflows/tests.yml).
