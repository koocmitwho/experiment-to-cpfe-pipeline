# GH4169 ingestion and evaluation plan

> Historical plan dated 2026-09-07. Editorial update: 2026-09-27. The [case README](../../../examples/gh4169_ultrasonic/README.md) gives the recorded results and current commands.

## Data and design

Use Mendeley DOI 10.17632/v487vwmd7r.1, DATA.xlsx Sheet1 A4:J13.
The source contains eight NO. specimens and T1/T2. The paper's public material
description identifies ten GH4169 specimens. Fixed inputs are column D mean
attenuation (dB/mm) and column F mean longitudinal velocity (m/s); column C
supplies mean metallographic grain diameter (um).

Create one SamplePackage/HDF5 per specimen through the XLSX block adapter,
preserving specimen identity, original heat-treatment strings, C/D/F values,
worksheet/row references, original file identity and conversion receipts.
`target_specimen` declares the source specimen column and basis. Source checks
compare physical specimen and worksheet/row partitions while preserving the
whole-file source chain.

Development pairs are NO.1/NO.5, NO.2/NO.6, NO.3/NO.7 and NO.4/NO.8.
Each outer holdout uses one pair; the other six specimens supply three inner
4/2 fits. Validation selects each checkpoint, and three members average the
outer predictions. Four final members use 6/2/2 training/validation/T1+T2 splits
and equal-weight averaging. Fixed settings are hidden=[4], seed=17,
learning_rate=0.003, epochs=1500 and patience=200.

Mean and OLS baselines fit the applicable development subset. Ridge candidates
are 0.01, 0.1, 1, 10 and 100, selected by inner validation before fitting the
available development population. Normalization uses each model's fitting rows.
Report development-outer and author-test MAE/RMSE, with specimen predictions.
