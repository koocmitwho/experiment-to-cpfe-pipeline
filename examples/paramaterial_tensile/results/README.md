# Example output

These files were generated by this portable example using the installed public
`experiment-to-cpfe 0.3.1` wheel on Windows / Python 3.12.10. They contain only
plots, numeric comparisons and a summary without machine-specific paths.

`summary.json` binds the output to input and processing hashes. It records
transfer and calculation consistency for these three specimens, not material
calibration, generalization or human time savings.

The figures, tables and source-derived summary are adaptations of the
CC BY 4.0 experimental curves; retain the attribution and transformation
description in [SOURCES.md](../SOURCES.md) when reusing them.
